# KPVault

**KPVault 是一个管理账号密码的 Windows 桌面软件。** 所有账号和密码存在一个加密的 `.kdbx` 文件里（KeePassXC 的格式），打开它需要一把主密码；KPVault 管的是「平时怎么用它」——搜条目、一键复制、自动备份、多台电脑同步、在浏览器登录框里直接填进去。

真正的加解密、读写库、合并库全部交给本机已安装的 `keepassxc-cli`。应用不解析 `.kdbx`、不实现任何密码学算法，所以你手里始终是**标准的 KeePass 库**，随时能用 KeePassXC 官方客户端或其它 KeePass 工具打开。

> English: [README.en.md](README.en.md)

### 它解决什么问题

| 平时的麻烦 | KPVault 的做法 |
| :--- | :--- |
| 几百条账号，翻半天找不到那一条 | 边打边筛（标题 / 用户名 / URL / 分组），`Ctrl+C` 直接把当前条目密码送进剪贴板 |
| 怕哪天库文件坏了、或者误删了 | 每次写入前自动备份（留 20 份），每 7 天随机抽检一份能否解密，坏了在主界面常驻告警 |
| 公司、家里两台电脑的库对不上 | 内置 WebDAV 同步（坚果云）：写完自动上传；两端都改过时不静默覆盖，存成冲突副本等你合并 |
| 登录页每次都要手打密码 | 自带浏览器扩展，点一下就填；也可以只填账号（不用解密）或只填密码 |
| 想把别的密码管理器的清单搬过来 | CSV 导入 / 导出，分组层级一起还原 |

**适合谁**：已经在用（或想用）KeePass 格式存密码，又希望有个顺手的桌面界面来管理的人。

**不适合谁**：不想在本机装 KeePassXC 的人（安装包刻意不打包它）；需要 macOS / Linux / 手机端的人（当前只发布 Windows x64）；想要云服务、多账号协作、客服支持的人——这是作者自用的单机工具。

> ⚠️ **两个硬前提**
>
> 1. **安装包不含 KeePassXC。** 应用只是界面：先在 [KeePassXC 官网](https://keepassxc.org/download/) 装好（≥ 2.7.0），或解压下载页附带的 portable zip，并让应用找到 `keepassxc-cli.exe`。
> 2. **主密码不保存在任何地方，也找不回来。** 忘了就等于永久失去这个库，备份同样是加密的，一样解不开。

## 快速开始

从零到「能在浏览器里填密码」大约 5 分钟。只需要两个文件，都在 [GitHub Releases](https://github.com/billgoto/kpvault-releases/releases/latest)：`KPVault-Setup.exe`（应用）和 `KeePassXC-2.8.0-x64.zip`（运行必需组件）。

### 第 1 步：准备 KeePassXC

把 `KeePassXC-2.8.0-x64.zip` 解压到一个固定目录（例如 `D:\Portable\KeePassXC-2.8.0-x64`），或者从 [KeePassXC 官网](https://keepassxc.org/download/) 安装（**≥ 2.7.0**，推荐 2.8.0）。

> 应用不打包 KeePassXC，它只是界面：真正的加解密由本机 `keepassxc-cli` 完成。

### 第 2 步：装应用、过首屏

1. 运行 `KPVault-Setup.exe`（可自选安装目录，会创建桌面快捷方式）。
2. 首次启动会自动探测 `keepassxc-cli`。找不到时点「选择 KeePassXC 目录」，选第 1 步解压出来的文件夹（也可以「选择 exe 文件」直接指定 `keepassxc-cli.exe`；顶栏另有「指定 KeePassXC 目录」）。
3. 建库或恢复库：
   - 新用户 →「创建数据库」→ 设主密码（要输两次）；
   - 已有库 / 换新电脑 →「从 WebDAV 恢复…」，把远端库下载下来；
   - **不要在两台机器上各自新建库**，那会变成两个互不相干的库。
4. 解锁进入主界面。

> 🔑 主密码不保存在任何地方、也没有找回途径。忘记就等于永久失去这个库，备份也一样解不开。

### 第 3 步：加一条账号，确认读写链路通

点左侧「新建」（`Ctrl+N`）→ 填标题、用户名、密码、URL →「保存」→ 在列表里点这条 →「复制」。

复制成功说明从界面到 `keepassxc-cli` 的读写已经通了，剩下那次配置只跟浏览器有关。

### 第 4 步：配置浏览器插件

插件是随应用分发的 MV3 未打包扩展，需要手动加载**一次**。它不依赖 KeePassXC-Browser 官方扩展。

**4.1 应用侧取令牌**

1. 顶栏「设置」→「浏览器填充」。
2. 确认「启用本地桥」已勾选（默认开启），下方显示「运行中」。
3. 点「配对令牌」右侧的「复制」（64 个字符）。
4. 点「打开扩展目录」（安装版位于 `<安装目录>\resources\browser-extension\`）。

**4.2 浏览器侧加载扩展**

1. Chrome 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选中 4.1 第 4 步打开的那个目录。
4. 点工具栏上的扩展图标（名字是「KPVault 填充」）→ 把令牌粘进输入框 →「保存并连接」。端口保持 `47823`，与应用里「本地端口」显示的一致。

**4.3 验收**

打开任意登录页 → 点扩展图标 → `已匹配` 页签里应列出该站点的条目 → 点一条即填充。库锁着时会先弹解锁窗口，解锁后**自动续做**刚才被中断的填充。

### 卡住时看这里

| 现象 | 处理 |
| :--- | :--- |
| 设置里显示「未运行」，并提示端口被占用 | `47823` 被别的进程占了，最常见是托盘里还留着一个 KPVault → 退出它再回来开桥。端口固定不顺延 |
| 扩展显示「连不上本机应用」 | 点一下账号会自动拉起应用（也可在弹窗里点「启动 KPVault」）；已在运行则回 4.1 检查桥是否启用、端口是否一致 |
| 扩展提示令牌不匹配 | 令牌是 64 个字符，多半没复制完整：点扩展里的「重新配对」重新粘贴 |
| 想让每次填充都确认一次 | 设置里打开「填充前在应用内确认」（默认关闭，此时令牌是唯一门槛，见 [§9](#9-浏览器自动填充)） |

## 1. 它是什么

一句话：**KeePassXC 的界面层**。它把 `keepassxc-cli` 包成一个桌面应用，自己不碰加密，也不接管库格式。

和直接用 KeePassXC 官方客户端比，差别在这几处：

| | KeePassXC 官方客户端 | KPVault |
| :--- | :--- | :--- |
| 定位 | 完整的 KeePass 客户端（GUI + CLI + 浏览器集成） | 只是界面层：加解密、读写库、合并全部转发给 `keepassxc-cli` |
| 操作路径 | 多窗口 + 菜单栏 + 工具栏 | 单窗口自绘标题栏：左分组树、右详情，搜索即筛选，`Ctrl+C` 直接复制当前条目密码 |
| 自动备份 | 可在设置里开启「保存前备份」 | 默认开启：写前备份留 20 份，每 7 天抽检一份能否解密，坏了主界面常驻告警 |
| 多设备 | 用网盘同步库文件（依赖外部工具） | 内置 WebDAV：写完上传、定时比对；两端都改过时存冲突副本，并支持条目级合并 |
| 浏览器填充 | 需装 KeePassXC-Browser，走官方协议 | 自带 MV3 扩展 + 本地桥（令牌配对）；右键菜单可直接指定要填哪个框 |

技术上分这几层：

| 层 | 实现 |
| :--- | :--- |
| 加密引擎 | 本机 `keepassxc-cli`（创建/解锁/增删改查/导出/合并），应用不解析 `.kdbx`、不实现任何密码学算法 |
| 桌面界面 | Electron 主进程 + Vue 3 / Pinia 渲染进程；自绘标题栏、系统托盘 |
| 数据同步 | 内置 WebDAV 同步主库（写库后上传、定时比对远端、冲突存副本），也支持网盘同步盘带来的外部变更检测 |
| 浏览器填充 | 自研 MV3 扩展 + 应用内本地桥（`127.0.0.1` + 配对令牌），不依赖 KeePassXC-Browser 官方扩展 |
| 更新分发 | GitHub Releases 上的 `update.json` 负责版本检查，安装包也从同一个 Release 下载；**只提醒，不自动下载或安装** |

**明确不做的事**：不打包/分发 KeePassXC 二进制，不保存主密码，不在渲染进程持有主密码明文，不自动安装更新，不做静默的自动冲突合并。

安全基线：渲染进程通过 `contextBridge` 白名单访问主进程（`sandbox: true`、`contextIsolation: true`、`nodeIntegration: false`）；主密码只在主进程内存中以 `Buffer` 形态存在，锁定即零化；托盘菜单不显示任何条目内容。

## 2. 功能总览

| 功能 | 说明 |
| :--- | :--- |
| 登录式解锁 | 独立解锁页，自动聚焦、Enter 提交、密码显隐、强度提示；主密码仅本地解密 |
| 条目管理 | 新建/编辑/查看/删除/移动到其他分组；字段为 分组、标题、用户名、密码、URL、备注 |
| 生成随机密码 | 密码框右侧「生成」：默认 20 位，长度 8–64 可调、可关掉符号，排除易混淆的 `I l 1 O 0`；四类字符必各有一个 |
| 改主密码 | 设置 → 主密码：填当前密码 + 新密码（≥ 8 位，输两次）→ 整库重加密。写前自动备份（旧密码仍能打开那份备份），成功后当前会话直接切到新密码、不退回解锁页 |
| 分组管理 | 新建子组、重命名、删除整组（含组内条目，不可恢复）；分组可逐个收起/展开（组名右侧显示条目数），悬浮时才显示操作按钮 |
| 搜索 | 实时筛选标题/用户名/URL/分组，搜索框内有清除叉号；另有「搜备注」走 CLI 全文检索 |
| CSV 导入 / 导出 | 带 `group` 列的 CSV 互通：导出整库明文（可再导回，分组层级一并还原）；导入逐条写入、重名自动加后缀、进度可见 |
| 密码查看与复制 | 按需解密显示、一键复制；剪贴板 **25 秒**后自动清除，且清除前比对内容避免误清 |
| 自动备份 | 每次写入前自动备份，保留最近 20 份；手动备份不清理；每 7 天随机抽检一份能否解密 |
| WebDAV 同步主库 | 坚果云等 WebDAV 服务，写后自动上传、定时比对、冲突副本；新设备可直接从远端恢复数据库 |
| 外部变更与冲突合并 | 检测同步盘落盘的改动，提示「载入」；冲突副本条目级合并，合并前自动备份、副本归档不删除 |
| 浏览器自动填充 | 扩展弹窗按 已匹配/全部/收藏/最近 列出条目，支持搜索、填充、复制账号/密码、保存当前页登录、页面内解锁；输入框右键菜单可直接填入（不依赖自动识别输入框） |
| 会话保护 | 空闲自动锁定（1/5/15/30 分钟）、休眠/锁屏/切走锁定、系统时间跳变锁定、手动锁定 |
| 托盘与快捷键 | 关窗最小化到托盘、托盘右键退出、可选全局呼出快捷键、应用内快捷键 |
| 检查更新 | 默认开启，启动 30s 与每 24h 检查一次，有更新时顶栏版本号高亮，点击跳下载页 |

## 4. 安装与首次启动

1. **准备 KeePassXC**：从[官网](https://keepassxc.org/download/)安装，或把下载页的 `KeePassXC-2.8.0-x64.zip` 解压到一个固定目录（例如 `D:\Portable\KeePassXC-2.8.0-x64`）。
2. **安装应用**：运行 `KPVault-Setup.exe`（NSIS，可自选安装目录、会创建桌面快捷方式）。
3. **首次启动会自动探测 `keepassxc-cli`**，顺序为：配置里记住的路径 → 常见安装目录（`Program Files`、`LOCALAPPDATA\Programs`、chocolatey、scoop）→ `PATH`。若找不到，进入第 1 段引导页：
   - 「选择 KeePassXC 目录」：选 portable 解压后的文件夹，应用会下探一层子目录找 `keepassxc-cli.exe`；
   - 「选择 exe 文件」：直接指定 `keepassxc-cli.exe`；
   - 「重新检测」/「去下载」：重装或升级组件后用。
   - 顶栏也常驻「重新检测 KeePassXC」和「指定 KeePassXC 目录」两个按钮，指定一次会记住。
4. **建立或恢复数据库**：库位置固定为 `%APPDATA%\KPVault\data\main.kdbx`（v1.44 起不再放安装目录），不支持更换（避免与网盘同步互相覆盖）。第 2 段引导页有两个选择：
   - 「创建数据库」→ 设置主密码（有强度提示，需再输一次）→「创建并解锁」；
   - 「从 WebDAV 恢复…」→ **换新电脑时用这个**，选服务商（坚果云）、填用户名与应用密码，把已有库下载下来。不要在两台机器上各自新建库，否则会变成两个不同的库。
5. **解锁**：之后每次启动进入登录式解锁页，输入主密码（可点眼睛切换明文），按 Enter 或点「解锁」。

> 🔑 **主密码不会保存在任何地方，也无法找回**。忘记主密码就等于永久失去这个库，请务必妥善保管。

## 5. 界面导览

窗口使用**完全自绘标题栏**：没有系统菜单栏，也没有最大化按钮；整条顶栏都是可拖动区域，右侧只有「最小化」和「关闭」。

| 区域 | 内容 |
| :--- | :--- |
| 顶栏 | 应用名、KeePassXC 版本状态、重新检测/指定目录、备份、设置、版本号（检查更新）、锁定、窗口控制 |
| 左侧栏 | 搜索框（有筛选时右侧出现清除叉号）、新建、搜备注、新建分组、导入/导出 CSV、按分组排列的条目列表（分组可折叠） |
| 内容区 | 条目详情/编辑表单，以及互斥覆盖的面板：设置、更新、冲突副本、备份、导入 CSV、导出 CSV |
| 提示条 | 检测到库文件被外部修改或出现冲突副本时，在主视图上方显示「载入」「查看副本」 |

点左侧栏（选条目、切分组、搜索、新建）会自动收起当前面板，回到列表视图。

## 6. 日常使用：条目、分组、搜索

### 6.1 条目

- **新建**：点左侧「新建」或按 `Ctrl+N`，填分组、标题、用户名、密码、URL、备注 →「保存」。分组不存在会自动创建，写入前会自动备份。
- **查看**：点列表中的条目。密码默认以圆点显示，点「显示」按需解密，点「复制」复制到剪贴板（25 秒后自动清空）。
- **编辑**：点「编辑」；密码框留空表示**不修改**，填了才更新；编辑时分组不可改，请用「移动到…」。
- **生成密码**：密码框标签行右侧「生成」→ 填入一个随机密码并切成明文，下方会出现参数条（长度 8–64、是否含符号），改完点「再生成」。默认 20 位，四类字符各至少一个，并排除 `I l 1 O 0` 这类易抄错的字符。
- **移动**：点「移动到…」输入目标分组路径。
- **删除**：点「删除」后需再点一次「确认删除」。条目会被彻底删除（应用会自动补删库的回收站副本），**不可在应用内撤销**，必要时从备份恢复整库。

### 6.2 分组

**收起 / 展开**：点分组标题整行即可折叠，三角朝右表示已收起；组名右侧的数字是组内条目数，折叠后也看得到这组有多少条。分组 ≥ 3 个时，工具条会出现「全收起 / 全展开」。搜索或搜备注期间分组会**强制展开**，避免命中的条目藏在折叠组里；清空筛选后恢复原来的折叠状态。

鼠标悬浮在分组名上才会浮出三个按钮（不占布局、不会把行撑宽）：

| 按钮 | 作用 |
| :--- | :--- |
| `＋` | 在该分组下新建子组 |
| `✎` | 重命名分组（会逐条搬运组内条目，有进度提示） |
| `×` | 彻底删除分组及组内全部条目，需二次确认，**不可恢复** |

根组显示为「（根组）」，不可重命名或删除。

### 6.3 搜索

- 顶部搜索框实时筛选**标题 / 用户名 / URL / 分组**，`Ctrl+F` 可直接聚焦。
- 「搜备注」调用 CLI 做备注全文检索，结果多时会被截断，请缩小关键词。
- 有搜索内容或备注筛选时，搜索框右侧出现 `×`；点它或按 `Esc` 恢复完整列表。

### 6.4 导入 / 导出 CSV

用来和别的密码管理器互通，或者把账号清单批量搬进来。侧栏「导入 / 导出」两个按钮。

**导入**

- 文件第一行必须是字段名，认 `name`（标题，也认 `title`）/ `url` / `username` / `password` / `group`（可选）；**列顺序不限**，中英文表头都认（`标题`、`网址`、`用户名`、`密码`、`分组`）。
- 分隔符自动识别 `,` / `;` / `Tab`；编码支持 UTF-8、带 BOM 的 Excel CSV 与 GBK。
- 先显示预览（标题/用户名/URL/是否有密码，**密码不在界面里出现**），确认后填目标分组再写入：
  - 文件没有 `group` 列 → 全部写入目标分组（默认「导入」）；
  - 文件有 `group` 列 → 写入「目标分组 / 文件里的分组」，目标分组留空则完全按文件层级还原。
- 逐条写入（每条约 1 秒，有 x/N 进度），写前只备份一次；**同名不覆盖**，自动加 ` (2)` 后缀。
- 密码全程只在主进程内存里，导入结束或锁屏即清空。

**导出**

- 一次解密导出整库，字段为 `name,url,username,password,group,notes`，UTF-8 带 BOM（Excel 打开中文不乱码），**导出的文件可直接再导入**。
- 回收站里的条目不导出；不含 TOTP、附件、自定义字段、时间戳。
- ⚠️ **导出的是明文**：任何拿到这个 CSV 的人都能看到全部密码。它不能当备份用，请只存到加密盘并及时删除。

## 7. 备份与恢复

点顶栏「备份」打开面板：

| 操作 | 说明 |
| :--- | :--- |
| 立即备份 | 手动生成一份，不会被自动清理 |
| 抽检一份 | 现场验证某个备份能否解密 |
| 打开目录 | 打开 `%APPDATA%\KPVault\backups\` |
| 恢复 | 点两次确认；**恢复前先校验该备份可解密**，并把当前库另存一份，因此恢复本身也可回退 |

规则：每次写入前自动备份，保留最近 **20** 份；应用每 **7 天**随机抽检一份，失败会在主界面常驻告警。备份是同一库的加密副本，解密仍需要主密码。

## 8. WebDAV 同步主库

在「设置 → WebDAV 同步主库」启用并填写：

| 配置项 | 说明 |
| :--- | :--- |
| 服务商 | 下拉框，目前只有「坚果云」（`https://dav.jianguoyun.com/dav`）；将来加别家只需在此下拉里多一项 |
| 用户名 | 坚果云是注册邮箱 |
| 密码 | **应用密码**（网页端 → 账户信息 → 安全选项 → 第三方应用管理 → 添加），不是登录密码 |
| 远端目录 | 默认 `/kpvault`，库文件名为 `main.kdbx` |
| 写库后自动上传 | 默认开启 |
| 检查远端的间隔 | 30 秒 / 1 分钟 / 5 分钟 / 15 分钟，默认 1 分钟 |

「测试连接」验凭据，「立即同步」手动触发。密码用系统 `safeStorage` 加密保存；若系统不支持，界面会明确提示令牌/密码以明文存于配置文件。

**同步行为**：写库成功后上传，定时比对远端；**两端都改过时不会自动覆盖**，而是把远端版本存成冲突副本并暂停自动同步，直到你在「冲突副本」面板处理完。

### 冲突副本合并

点提示条的「查看副本」→ 选一份 → 点两次「合并」。合并调用 `keepassxc-cli merge`，是**条目级 last-write-wins**：同一条目两端都改过时较新的一方覆盖较旧的一方，被覆盖的修改会静默丢失；一端的删除也可能被另一端复活。合并前会自动备份，合并后副本改名为 `.merged-时间` 归档（**不删除**），并列出每处变更。

### 外部变更

如果库文件被同步工具等其他程序改动，顶部提示条会说明当前显示的是旧内容，点「载入」刷新；若期间本地也有写入，会提示「检测到外部覆盖」，可从备份恢复并合并。

> 开着微信二次验证会让 WebDAV 返回 **403**，需先在坚果云网页端关闭。

## 9. 浏览器自动填充

这是可选功能，由「自研扩展 + 应用内本地桥」组成：桥只监听 `127.0.0.1:47823`，校验扩展 Origin 与配对令牌；扩展是 MV3 未打包扩展，需手动加载。**端口固定为 `47823`，被占用时明确报错、不再自动顺延**（顺延会让扩展连到旧端口而永久失联）。

**配置步骤**

1. 应用「设置 → 浏览器填充」启用本地桥（默认开启），点「复制」取配对令牌。
2. 点「打开扩展目录」（打包后位于 `<安装目录>\resources\browser-extension\`）。
3. Chrome / Edge 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择该目录。
4. 点扩展图标 → 粘贴 64 位令牌 →「保存并连接」；端口保持 `47823`。设置页「本地端口」旁有「复制」可一键取值；端口不一致时扩展会自动探测修正。令牌失效时点「重新配对」，或回设置页「更换」令牌。

**弹窗功能**：搜索框；`已匹配`（当前站点）/ `全部` / `收藏`（★）/ `最近` 四个页签；每行右侧「账号」「密码」一键复制（密码由主进程写入剪贴板、**25 秒后自动清除**，明文不回传给浏览器）；「刷新列表」；「保存此页登录」（读取当前页面表单里的账号密码存成条目）。

**页面内**：登录输入框右侧有填充浮层；密码库锁定时可在弹窗或独立解锁窗口输入主密码，解锁成功后会**自动续做**刚才被中断的填充、保存或复制。未解锁时列表仍可显示（来自本地缓存），但取明文必须解锁。

**登录后保存提示**：提交登录表单后，若该站点还没有这个账号，气泡问「把这个账号保存到 KPVault？」；已有同账号但**密码不同**时问「用新密码覆盖？」；**密码与库里一致则完全不弹**（不会用"覆盖"打扰你）。

**右键菜单**：在要填的输入框上右键 → `KPVault` → `填入账号` / `填入密码`（两项分开）。这条入口不依赖"我们认出输入框"（页面浮层靠 `input[type=password]` 之类的选择器，自定义控件、聚焦时机不对的页面会漏），而是由浏览器判定「可编辑元素」后把菜单给你，所以页面结构再怪也能用。

语义很简单：**填到你右键的那个框**。不找它配对的账号框/密码框，也不判断"这像不像登录框"——密码框上点「填入账号」就往密码框里写账号，文本框上点「填入密码」就往文本框里写密码，`input` / `textarea` / `contenteditable` 都支持。当前站点只有一条匹配时直接填；有多条时右上角弹候选面板让你选一条；库锁定时会先弹解锁窗口，解锁后填回你右键的那个框。

`填入账号` 和 `填入密码` 的差别只在数据来源：**账号直接取扩展缓存里的用户名，一次都不解密**，所以库锁着也能填；密码必须解密。

**应用没启动时**：点账号（页面浮层、右键「填入密码」、弹窗列表都算）会**自动拉起应用并接着把这次填充做完** —— 浏览器首次会弹「打开 KPVault？」确认框，点「打开」即可（若出现「始终允许」复选框，勾上以后不再提示）；应用起来后若还没解锁，窗口已经在最前面、密码框已聚焦，输完主密码就会自动填入，不用切回浏览器再点一次。最多等 20 秒（解锁最多再等 90 秒）。不想让网页唤起应用，可在弹窗底部取消勾选「连不上时自动启动 KPVault」，那时只提示，由你自己点「启动 KPVault」。自动拉起与按钮都依赖安装版注册的 `kpvault://` 协议，开发模式/绿色版无效；若应用其实已在运行却仍连不上，请检查「设置 → 浏览器填充」里本地桥是否启用、是否有端口占用报错、端口是否与扩展一致（默认 `47823`，应用端口固定不漂移；扩展会自动探测 47823–47832 并修正自己）。

> ⚠️ **安全取舍**：「填充前在应用内确认」默认**关闭**，即点「填充」/「密码」直接把明文交给浏览器或剪贴板，配对令牌是唯一门槛——任何拿到令牌的本机程序都能取到明文。若不完全信任本机环境，请在设置里打开这个开关（打开后填充与复制密码都会先弹确认框）。

## 10. 会话、托盘与快捷键

**自动锁定**：空闲 1/5/15/30 分钟（默认 5 分钟）；系统休眠、关机、锁屏、切走应用，以及检测到系统时间跳变超过 5 分钟，都会立即锁定。顶栏「锁定」或 `Ctrl+L` 可手动锁定。

**托盘**：关窗默认**最小化到托盘**（可在设置改为「直接退出」）；左键托盘图标显示/隐藏窗口，右键菜单包含 显示主窗口、锁定、打开库所在目录、全局快捷键开关、**退出**。托盘是默认的退出入口，图标会区分已解锁/已锁定。

| 快捷键 | 作用 |
| :--- | :--- |
| `Ctrl+F` | 聚焦搜索框 |
| `Ctrl+N` | 新建条目 |
| `Ctrl+Shift+N` | 新建分组 |
| `Ctrl+L` | 立即锁定 |
| `Ctrl+C` | 无选中文本时复制当前条目密码（有选区时正常复制文字） |
| `Delete` | 删除当前条目（仍需点「确认删除」） |
| `Esc` | 取消分组输入 / 退出编辑 / 清除筛选 |
| `Ctrl+Shift+Space` | 全局呼出或隐藏窗口（**默认关闭**，在设置或托盘开启；被系统/输入法占用时会注册失败） |
| `Ctrl+X / V / A / Z / Y` | 标准编辑操作（去掉系统菜单后由应用补回） |

输入框内只接管 `Esc` / `Ctrl+F` / `Ctrl+L`，其余按键不拦截，避免影响正常编辑。

## 11. 检查更新

- 默认开启。启动 30 秒后检查一次，之后每 24 小时一次；顶栏版本号按钮可手动检查。
- 更新清单 `update.json` 与安装包放在同一个 GitHub `latest` Release（匿名可访问、URL 恒定），客户端只认这个地址；打开链接的域名白名单写死在代码里，不动态信任清单内容。
- 有更新时版本号按钮变成「有新版本 vX.Y.Z」并高亮，点开可看更新说明，再点「打开下载页」跳到 GitHub Releases。
- **应用不会自动下载或安装**：安装包没有代码签名，自动安装的风险大于便利。请自行下载 `KPVault-Setup.exe` 覆盖安装。**v1.44 起密码库存在 `%APPDATA%\KPVault\data\`，升级和卸载都不会删除它**；从 v0.2.2 及更早版本升级时，安装器会在卸载旧版**之前**把 `<安装目录>\data\main.kdbx` 自动迁移过去（目标已有库则整个跳过，绝不覆盖）。日常仍建议定期备份，但不必再为升级手动挪库。

## 12. 数据与配置位置

| 内容 | 位置 |
| :--- | :--- |
| 密码库 | `%APPDATA%\KPVault\data\main.kdbx`（固定，不可更改；v1.44 起不再放安装目录） |
| 应用配置 | `%APPDATA%\KPVault\config.json`（不含主密码） |
| 卸载保护副本 | `%APPDATA%\KPVault-vault-keep\main.kdbx`（仅 `--delete-app-data` 卸载后由应用回捞，正常卸载不会用到） |

| 自动/手动备份 | `%APPDATA%\KPVault\backups\` |
| 同步状态 | `%APPDATA%\KPVault\sync-state.json` |
| 浏览器扩展 | `<安装目录>\resources\browser-extension\` |

配置里包含 WebDAV 应用密码与浏览器配对令牌，均优先使用系统 `safeStorage` 加密；**不要把这些文件同步到不受信任的位置**。

## 13. 常见问题

| 现象 | 处理 |
| :--- | :--- |
| 启动提示「找不到 keepassxc-cli」 | 确认已[安装/解压 KeePassXC](https://keepassxc.org/download/) 且版本 ≥ 2.7.0；用「指定 KeePassXC 目录」选 portable 文件夹或直接选 exe，然后「重新检测」 |
| WebDAV 返回 403 | 用**应用密码**而非登录密码；关闭坚果云微信二次验证 |
| 扩展显示「连不上本机应用」 | 应用没运行 → 点账号会自动拉起（也可在弹窗点「启动 KPVault」，首次需在浏览器确认框点「打开」）；已运行 → 检查设置里本地桥是否启用、是否有端口占用报错（多半是还有另一个 KPVault 进程在托盘里）、端口是否与扩展一致（默认 `47823`，应用不会换端口）。若提示「端口已自动修正」，点一次「刷新列表」即可。令牌不对才需要「重新配对」 |
| 关掉窗口后程序没退出 | 默认最小化到托盘；托盘右键「退出」，或设置里把「关闭窗口时」改成「直接退出」 |
| 主密码忘了 | 无法找回。备份同样是加密库，也解不开，只能重建库 |
| 换了一台电脑 | 在首次启动第 2 段用「从 WebDAV 恢复…」下载已有库；**不要新建** |
| 升级后提示「还没有数据库」 | **只发生在 v0.2.2 及更早版本**：当时库在安装目录，覆盖安装被卸载器删了。把 `%APPDATA%\KPVault\backups\` 里最新的 `auto-*.kdbx` 复制成 `%APPDATA%\KPVault\data\main.kdbx`，或用首屏「从 WebDAV 恢复…」；**不要点「新建库」**。库文件已不存在时应用内「备份」面板无法直接恢复（该入口要求当前库存在） |
| 删了条目想撤销 | 应用内无撤销；可从备份面板恢复整库（恢复前会自动另存当前库） |
| 下载页里有两个文件 | `KPVault-Setup.exe` 是应用，`KeePassXC-2.8.0-x64.zip` 是运行必需组件，两个都要 |
